01 About Me

Crafting visual narratives with elegance & purpose.

I focus on the intersection between visual design, digital media, and strategic brand creation. My work explores how colors, typography, organic forms, and interactive mechanics create emotional connections between brands and people.

I believe design should be clean, intentional, and expressive. Whether I am crafting a visual identity system, building a digital app interface, or mapping out a rich visual narrative world, I approach every project with curiosity, attention to detail, and a refined aesthetic vision.

Project 02 Digital + Physical Experience

SERENA

YEAR: 2025
ROLE: UI/UX & Wearable Designer

Serena was a project created to address a problem related to anxiety attacks. The proposed solution combined a digital application with a physical wearable element. The physical element helps users count and follow their breathing, while the application supports the experience. I researched the users and developed a digital and physical solution. I designed the user flow, created the wireframes and developed the visual interface of the application.

Project 04 Modern Digital + Physical Game

JENGA

YEAR: 2025
ROLE: Interactive Game & UI Designer

This project transforms the traditional Jenga game into a more modern interactive experience. The physical game is connected to a mobile application. Each Jenga piece has a color, and each color is connected to different challenges that can appear through the application. I transformed the traditional Jenga game into a modern interactive experience. I designed a system that connected the physical pieces with a mobile application, using colors to assign different challenges.
